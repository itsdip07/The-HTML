### 📋 Lists

Learn how to organize information using different types of HTML lists.

* 🔢 **Ordered List**
* 🔘 **Unordered List**
* 📝 **Description List**

```html
<ol>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ol>
```

---

### 📊 Tables

Learn how to create structured data tables using HTML.

```html
<table>
  <tr>
    <th>Name</th>
    <th>Course</th>
  </tr>
  <tr>
    <td>Student</td>
    <td>HTML</td>
  </tr>
</table>
```

---

### 📝 Forms

Learn how to collect user input using HTML forms.

```html
<form>
  <label>Name:</label>
  <input type="text">

  <label>Email:</label>
  <input type="email">

  <button type="submit">Submit</button>
</form>
```

---

### 🧱 Semantic HTML

Understand meaningful HTML elements that describe the structure of a webpage.

```html
<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
```

✨ Semantic HTML helps make webpages more **structured, readable, accessible, and SEO-friendly**.

## 🎵 Multimedia

### 🎧 Audio

```html
<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
</audio>
```

### 🎬 Video

```html
<video controls width="500">
  <source src="video.mp4" type="video/mp4">
</video>
```

### 🖼️ Iframe

```html
<iframe
  src="https://example.com"
  width="600"
  height="400">
</iframe>
```
